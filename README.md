# AI Tools Radar

Hands-on evaluations of AI tools, platforms, and

---

## Why This Exists
I build AI agents for enterprise clients daily.
To do that well, I have to deeply understand 
the tools and platforms in this space —
what they're good at, where they fall short,
and which ones I'd actually recommend to a client.

This is my running log of that research.

## Evaluation Framework
Every tool is assessed on:
- Core capabilities & UX
- Pricing & value
- Enterprise readiness
- Gaps & limitations  
- Who it's best for
- Verdict & recommendation
